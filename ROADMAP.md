# SeviathStudio (Rust) — Roadmap

How every part of the project plan (`SeviathStudio_Project_Plan_EN.md`, Parts A–AV) gets built in this Rust app: in which order, with which technique, and what each step needs from outside (accounts, servers, hardware). Libraries named here are open source and GPL-3.0-compatible.

**Rules for every milestone:** it ships working (no placeholder buttons), it has tests and screenshot checks, settings it adds actually do something, and it never needs a paid service.

## What needs you (can't be done from code alone)

- **Supabase project** for accounts/library/shop/chats (free tier) — the first app's setup script can be reused; keys go in a local `.env`, never in the repo.
- **GitHub repo** for the public brush library (and for this code).
- **A tablet / camera / iPhone** for real-device checks of pressure and tracking — the app has test pages for both.
- **Your own AI** (Ollama/ComfyUI installed, or a free Gemini key) for the AI features — everything else works without it.
- **Platform accounts** (Twitch, OBS on your PC, PayPal for sellers) when their connectors are built.
- **Unity / Godot / Unreal** installed when the game runtimes (46) are built — they live in their own repos.
- **Your hand-drawn art** for the App Originals section and **people as moderators** for appeals and permanent-ban reviews.
